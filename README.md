# Supplementary Artifacts for A Layered Federated Architecture for Cyber Threat Intelligence Sharing

This repository contains supplementary artifacts associated with the anonymized manuscript:

**A Layered Federated Architecture for Cyber Threat Intelligence Sharing**

The materials support independent inspection of the empirical corpus, the sector classification process, and the Monte Carlo sensitivity analysis reported in the paper.

---

## 1. Purpose

The study evaluates a layered federated governance architecture for cyber threat intelligence sharing.

The empirical evaluation uses public Cyber Threat Intelligence (CTI) records to examine whether explicit contextual evidence can support selective and auditable routing to strategic N1 domains.

The supplementary artifacts are provided to improve:

- transparency of the evaluated corpus;
- auditability of the sector classification process;
- traceability of the reported sector associations;
- reproducibility of the Monte Carlo sensitivity analysis; and
- distinction between observed source records, routing eligibility, proposed downstream treatment, and modeled architectural utility.

The supplementary material should be interpreted together with the scope and limitations stated in the manuscript.
